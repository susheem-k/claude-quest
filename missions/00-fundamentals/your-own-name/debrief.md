**What this taught you:** `CLAUDE.md` isn't tied to one location — it's a convention
Claude Code reads wherever it's rooted. A project's `CLAUDE.md` (like First Contact's)
is about that project. This one was about your own persistent state in this game.
The same idea, applied twice at two different scopes, is exactly how Claude Code's
real memory works too: a project-root `CLAUDE.md` for project facts, a user-level
`~/.claude/CLAUDE.md` for things true about you across every project you touch.
