**What this taught you:** Claude Code reads a file named `CLAUDE.md` in your
project root automatically, at the start of every session — you don't have to
tell it to. Anything true about the project that you'd otherwise repeat every
time (how to run tests, coding conventions, architecture notes) belongs there
instead. It costs context on every session it's loaded into, so keep it to
facts that are actually project-wide, not a dumping ground for one-off notes.
