# Free Up the Room

*Ungraded. There's no file this command leaves behind, so there's nothing for
`check.js` to look at — say "check" whenever you're ready and it'll pass
automatically. The point of this one is trying the command, not clearing a gate.*

A long conversation eventually fills up the room it has to think in. `/compact`
replaces the history with a summary, so there's room again.

## Goal

Open a real `claude` session (in this sandbox or anywhere else — it doesn't matter
here) and run `/compact`. Optionally give it a focus, like `/compact focus on what we
changed`.

## Check

Always passes. Say "check" when you're ready to move on.
